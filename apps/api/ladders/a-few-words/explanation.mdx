## the idea

this ladder takes the password game's trick and points it at a funeral. each rule shows up only once every rule before it holds. if you saw all eight at the start, it would read like a form. seeing them one at a time is where the joke comes from.

## the turn

rule 3 asks you to write about someone the speaker didn't like. rule 7 then tells you the speaker is the person who died. the dislike you already wrote hasn't changed a word, but it now reads as self-loathing.

rule 8 turns the whole thing toward grace. a dark comedy that ends on the bleakest note it can find is just edgy, so the last lines have to give the room something.

## the words

the banned list takes out the easy funeral vocabulary: good, kind, generous, friend, loved. it bans the stems, so "lovely" and "friendship" are out too. the 55-word limit shows up after that, so whatever you used to fill the gap has to be short.
